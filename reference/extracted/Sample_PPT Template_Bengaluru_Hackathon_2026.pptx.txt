=== Slide 3 ===
Development with IBM Bob
1  REQUIREMENTS
Capture and clarify project goals, constraints, and acceptance criteria with Bob.
2  BOB CREATES PLAN
Bob generates a structured, step-by-step development plan with file structure and dependencies.
3  REVIEW & REFINE
Team reviews, adjusts, and approves the plan before any code is generated.
4  CODE GENERATION
Bob generates backend Python/FastAPI code, React TypeScript UI, and agent logic.
5  REVIEW OUTPUT
Team reviews generated code for correctness, style, and completeness.
6  RUN & VALIDATE
Run the application end-to-end and validate against the original requirements.
7  BOB EXPLAINS
Bob explains the implementation decisions and guides the team through the codebase.
8  QUALITY & TESTS
Bob generates tests, identifies edge cases, and suggests quality improvements.
9  DOCUMENTATION
Bob auto-generates README, API docs, and inline code documentation.

=== Slide 5 ===
Features of the Project
MULTI-AGENT AI SYSTEM
8 specialized agents collaborate through an orchestrator to simultaneously tackle groundwater, drought, crop, recharge, water budgeting, and reporting challenges.
No other system combines multi-agent AI with village-level explainable recommendations.
VILLAGE WATER HEALTH SCORE
Converts groundwater, rainfall, and demand data into a simple 0–100 health index — fully explainable.
WHAT-IF WATER SIMULATOR
Test scenarios — crop switching, reduced extraction — before committing to real-world action.
SMART CROP ADVISORY
Recommends water-efficient and drought-tolerant crops based on current, localized water conditions.
RISK-TO-ACTION INTELLIGENCE
Goes beyond detection — converts every drought and depletion insight into a prioritized action plan.
